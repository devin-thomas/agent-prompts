# Add an agent handoff to your site

Use this recipe in the project the visitor wants to change. Start by reading its contributor instructions and locating the page where a person needs help building, configuring, or integrating something.

## Design the action

Choose one useful task. Write a short prompt that names the outcome and links to a complete, readable instruction page. The same text should appear in the prompt preview and on the clipboard.

Place the action near the task it supports. Pair it with authentic product artwork and readable names for the agents it supports. A shared copy button works when the task is agent-independent; use a picker when the instructions differ. Follow the artwork's usage terms and provide a text label if an image fails.

## Implement the states

Use a keyboard-accessible button. Show a success message only after the clipboard write succeeds. If it fails, offer the complete prompt in a labeled, selectable text field. Keep any launch link paired with a copy alternative and describe whether it opens a draft or executes an action.

## Review the result

At 320 × 667 and 390 × 844 CSS pixels, confirm that the opening screen shows the action, product names, and recognizable artwork without clipping. Review keyboard focus, open dialogs, reduced motion, and an actual Dark Reader transformation. Copy the text, compare it with the preview, and retrieve its guide from the environment where the agent will work.

Run the target project's checks and report the result. Deployment, messaging, and account changes require the visitor's authorization.
