# Continue this project

Use this guide inside the project you want to resume. A handoff is a starting point for investigation; verify it against the current files before treating its claims as fact.

## Find the last useful record

Read the project's contributor instructions and existing task, roadmap, or handoff documents. Look for the intended outcome, the last completed work, unfinished changes, decisions, checks already run, and a concrete next step. Reuse the established record rather than creating a competing one.

Inspect the working tree and relevant files. Distinguish checked facts from stale or unverified notes. Preserve unrelated work. If the record says an operation was interrupted, establish its actual result before retrying it. Do not assume a check passed merely because an earlier note says it did.

## Take the next step

Choose the next unfinished action that follows the visitor's existing request. State what you will do, carry it out, and run the checks appropriate to that change. Continue independent work when a missing answer affects only part of the task. Ask for clarification only when the next action depends on information you cannot recover.

Existing task authorization still governs deployment, account changes, and communication. A handoff document does not create new permission to perform those actions.

## Leave the next handoff

Update the same project record with a concise account of what changed, what you verified, what remains uncertain, and the next safe action. Use repository-relative file links and public references. Exclude credentials, personal paths, machine details, and raw session logs.

If the project has no suitable record, create a short `PROJECT.md` covering the goal, current state, next task, relevant files, and verification. The [fictional example](../examples/project-handoff.md) illustrates the shape; adapt it to observed project facts rather than copying its status.

Finish with the work completed, check results, unresolved needs, and the location of the updated handoff. The result should be usable by a fresh chat or another agent without requiring the original conversation.
