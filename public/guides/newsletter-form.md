# Add an accessible newsletter signup form

Inspect the existing project and reuse its components, styles, and newsletter integration. Add one email field with a visible label, a clear subscribe action, and understandable consent copy appropriate to the product.

Use the existing subscription backend if available. If no integration is configured, create a clearly labeled local demo that does not send or store an address. Report the missing destination rather than presenting a fake successful subscription. Keep secrets out of browser code. Preserve the address when a submission fails, prevent duplicate submissions, and provide accessible status and error messages.

Verify invalid input, a successful test submission, a failed handler, keyboard use, and narrow layout. Run relevant checks and report the actual coverage. Do not subscribe real addresses, create paid accounts, send email, or publish without the user's authorization.

This is a public task recipe for the independent Agent Prompts demonstration, not an official agent integration.
